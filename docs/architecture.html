Code architecture · PHYS 3153 Project 10

How the simulation code fits together

Eight Python files, about 1,900 lines with comments. Three physics modules describe the films and the light; device.py turns that into a solar-cell efficiency; two driver scripts run it for every electrode and write the data that every figure and number in the report is drawn from.

Start reading here

device.py is the heart

Given the light that reaches the absorber and the electrode's sheet resistance, it finds the best finger spacing (silicon cell) or stripe width (perovskite module) and returns the efficiency. Everything above it prepares those two inputs; everything below it calls it many times.

The physics modules

From two numbers to optics

  • electrodes.py holds each film's carrier density n and mobility μ
  • physics.py turns them into a refractive index (Drude + band gap)
  • tmm.py sends sunlight through the layer stack

Reproducible

One command rebuilds it all

python run_all.py then python opaque.py. The random seed is fixed (20261105), so every run gives the same numbers. Nothing in the report is typed in by hand.
